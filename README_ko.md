# Pazzk EVSE (Archived)

🌐 **Available languages**: [English](README.md) | [한국어](README_ko.md)<br />
🔗 **Official Website**: [pazzk.net](https://pazzk.net)

> ⚠️ **이 저장소는 보관(Archive) 상태로 전환되었으며, 더 이상 유지보수되지 않습니다.**

Pazzk EVSE는 확장성과 신뢰성을 갖춘 전기차 충전 솔루션을 목표로 시작된 오픈소스 프로젝트입니다.
초기부터 듀얼 라이선스 모델을 채택하여 GPLv3 오픈소스 버전과 상업용 라이선스 버전을 함께 제공했습니다.

이후 프로젝트는 산업 환경에서 요구되는 높은 신뢰성, 인증 적합성, 장기 유지보수를 충족하기 위해 상용 제품 라인에 초점을 맞추게 되었습니다.

상업용 기능이 강화되고 보안 및 안전 기능이 고도화되면서,
관련 요구사항들이 설계적으로 깊이 고려되어야 했고
그 과정에서 구조적인 변경이 불가피했습니다.
결과적으로 제한된 리소스로 오픈소스 버전과 통합하거나
두 버전을 병행 유지하는 것은 현실적으로 어렵다고 판단했습니다.

## Commercial Edition

파직은 앞으로 전문성과 자원을 상업용 제품 개발에 집중할 예정입니다.
상업용 제품은 하드웨어와 함께 제공되거나, 독립적인 펌웨어 라이선스 형태로 판매됩니다.

자세한 정보는 [https://pazzk.net](https://pazzk.net) 또는
[contact@pazzk.net](mailto:contact@pazzk.net)으로 문의하세요.
